# Timeless Jewels

An e-commerce website for Timeless Jewels, a local business selling gold-tone jewelry that never tarnishes. I built it as a freelance project to make it easier for customers to find and buy jewelry online.

## Features
- Product catalog with search and filtering
- Shopping cart and checkout flow
- Responsive layout for phones and desktops

## Built with
HTML, CSS and JavaScript in a single page (`timeless-jewels.html`), with no build step. Open the file in a browser to view it.
